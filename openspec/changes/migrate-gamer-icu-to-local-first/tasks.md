# GAMER-ICU local-first migration implementation plan

This plan is the replacement for the Kiro development-to-deployment checklist. Tasks are ordered by dependency. Every task is mandatory unless explicitly marked complete below. Participant-level study data remains on the participant device and moves only through the explicit encrypted QR exchange to an institution-provisioned collector. Supabase is limited to approved, disclosure-safe cohort aggregates.
